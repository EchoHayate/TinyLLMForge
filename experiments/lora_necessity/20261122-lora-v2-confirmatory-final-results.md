## 1. 核心研究结论（一句话总览）

在消除天花板饱和、完成动态隔离核验与分词预算核验的全新 32 题多约束基准 `confirmatory_v2_r1` 上，对 `Qwen3-8B` 训练外挂 `rank-8` LoRA（8 道监督题 × 2 epochs = 16 步，8/8 道监督题训练 loss 全部单调下降）并进行四臂配对评估（`base`、`text`、`lora`、`lora_text`，共 96 个 episode / 192 次贪婪生成 / 1,536 个测试用例位置）：

1. **同信息主对照（`lora_text` vs `text`）无迁移净收益**：在 12 道同机制未见迁移题（`WT01..WT12`）上，两者通过率完全持平（均为 **`4 / 12`**，`both_right=4`、`both_wrong=8`、`wrong_to_right=0`、`right_to_wrong=0`、**`net_gain = 0`**）；在 12 道异机制保留题（`WR01..WR12`）上未发生退化（`lora_text=5/12` vs `text=4/12`，`right_to_wrong=0`，`net_gain = +1`）。
2. **上下文压缩对照（`lora` vs `text` 及 `lora` vs `base`）大幅省时但损失迁移准确率**：不拼长文本示例、仅挂载外挂 LoRA（`lora`）在速度上比 `text` 快 **`8.87×`**（48 次生成仅 `753.75` 秒 vs `text` 的 `6,686.32` 秒；69.09 秒的 LoRA 训练固定开销仅需 **`0.28` 道双轮题 / `0.59` 次单轮调用** 即可追平墙钟时间），但 **8 样本 16 步 LoRA 未能把可信示例中的算法规则无损压缩进权重**：`lora` 在迁移题上仅通过 **`2 / 12`**，低于 `text`（`4 / 12`，配对 **`net_gain = -2`**）且低于 `base`（`3 / 12`，配对 **`net_gain = -1`**），保留题则与 `base` 完全一致（`4 / 12`，`net_gain = 0`）。
3. **同信息文本上下文（`text` vs `base`）在同机制新题上有小幅正迁移但推理极贵**：将匹配复杂度的 8 道多约束示例放入上下文使迁移题通过数从 `base` 的 `3 / 12` 提升至 `4 / 12`（`wrong_to_right=3, right_to_wrong=2, net_gain=+1`），代价是输入 token 膨胀 **`7.76×`**（`167,982` vs `21,654`）、`eager` 无缓存生成墙钟膨胀 **`9.99×`**（`6,686.32s` vs `669.57s`）、峰值 allocated 显存增加 **`4.74 GiB`**。

## 6. 机制追问与 Gate G5 收敛训练消融实测（Plasticity–Stability 帕累托权衡）

对 Gate G4-B 生成代码的逐字节检查发现：在原固定协议（`lr=5e-5`、仅 `2 epochs = 16` 步）下，`lora` 有 `17 / 24`（`70.8%`）的首轮输出与 `base` 逐字符完全一致，`lora_text` 更有 `23 / 24`（`95.8%`）与 `text` 逐字符完全一致（训练结束平均 loss 仍停在 `0.7812`）。

为严格区分“步长饥饿欠拟合”与“8 样本参数记忆的本质泛化边界”，在完整保留上述预设确认性结论不变的前提下，补充执行了单次 **Gate G5 收敛训练诊断消融**（`run_id=70e8d05aec96c93abd5145e76182c126`，独立复核 `APPROVE`，0 P0/P1/P2）：保持同一 `V01..V08` 监督集、`rank=8, alpha=16, q_proj/v_proj` 与 `WT01..WR12` 评估集完全不变，改用标准 LoRA 学习率 `lr=2e-4`（线性衰减至 `2e-5`）训练 **`12 epochs = 96` 步**，并在挂载前用 `WT01`、`WR01` 两题 `base_canary` 验证跨会话贪婪输出 **100% 逐位复现**（`{"WT01": true, "WR01": true}`）。

### 6.2 最终科学定论（Plasticity–Stability Trade-off vs Context Cost）

Gate G4-B 与 Gate G5 共同给出了完整、闭合、无歧义的机制结论：
1. **外挂 LoRA 确实能把上下文示例中的算法修复规律压缩进权重并以 `9.20×` 速度推理**：当训练充分收敛（96 步，`loss: 0.762 → 0.013`）后，`lora_conv` 在不看任何提示词示例的情况下，成功在未见同机制题 `WT05`、`WT11` 上实现零上下文迁移，同机制迁移得分从 `2/12` 跃升至 **`4/12`，正面追平长提示词 `text`（`4/12`）**，且推理耗时从 `111.4` 分钟骤降至 **`12.1` 分钟**（95.6 秒训练开销跑 **`0.39` 道题** 即回本）。
2. **但少样本（8 题）全局权重更新存在本质的“可塑性—稳定性（Plasticity–Stability）”跷跷板**：
   - 欠更新（16 步）：保住了 `4/12` 保留能力（零遗忘），但学不进迁移规律（`2/12`）；
   - 强收敛（96 步）：学会了 `4/12` 同机制迁移，但 8 条窄分布样本上的强梯度记忆改变了注意力投影偏好，导致异机制保留题出现 `-2` 退化（`4/12 → 2/12`）；
   - 相比之下，**上下文记忆（`text`）通过 KV 注意力仅在当前请求局部条件化，不修改全局权重，因而唯一同时保住了迁移（`4/12`）与保留（`4/12`）总分优势（`8/24` vs `6/24`），代价则是每次推理承受 `7.78×` 输入长度与 `~9×` 延迟膨胀**。
