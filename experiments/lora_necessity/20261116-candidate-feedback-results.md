# 候选源码与公开反馈组件结果

日期：2026-11-16。

## 已完成

新增 `candidate_feedback.py`，不修改生成器、提示渲染、训练和冻结数据。

- 检查模型原始输出是否符合一个同名同参数函数的规则，不替模型剥离
  Markdown、补全源码或删除说明文字。AST/compile 仅检查语法，不运行函数。
- 构造按公开用例排序的执行请求，不附带 expected 或隐藏答案。
- 将受信执行器收据与尝试、任务、组别、轮次、候选原文及用例绑定。
  错配、缺失、重复、非法 JSON 或基础设施状态不能冒充正常测试反馈。
- 依据公开期望值计算 pass/mismatch，或保留 program_error/timeout/output_limit。
  模型只收到现有 `second_round` 支持的用例编号和状态，不收到原始进程输出。
- 无效源码只接受空收据，返回 invalid_source，不声称执行过测试。

收据哈希只用于绑定，不认证执行器；未来受信控制端仍须承担隔离、
单次执行、计时、完整性和成本记账。函数入口只处理第一轮公开反馈，
不提供最终隐藏评分或第二轮执行功能。
