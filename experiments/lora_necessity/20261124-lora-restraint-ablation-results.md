## 1. 一句话终极结论

通过路线 A（外置隐状态开关）与路线 B（强约束 `64步 KL=2.0` + 满步数放宽约束 `96步 KL=1.0`）三组受控实验，我们把 8 样本外挂 LoRA 的规律迁移与保留边界彻底摸清了：

1. **最优甜点锁定在 `lora_kl_64`（64 步 + 强 KL 锚定 `lambda_kl=2.0`）**：在不改动任何推理代码（`14.62 MiB` 纯标准 LoRA、比长提示词快 **`8.89×`**、`0.79` 道题回本）的前提下，**100% 救回了全部保留集退化（`4 / 12` 零遗忘，追平 `base` 与 `text`）**，同时保住 `WT05` 零上下文迁移（`3 / 12`），拿下全部外挂 LoRA 变体中的最高总分 **`7 / 24`**。
2. **满步数 `lora_kl_96`（96 步 + 放宽 `lambda_kl=1.0`）反证了“过深压低 8 样本 Loss 必伤保留且不再涨迁移”**：当把步数拉满到 96 步、将 `V06/V07/V08` 监督 loss 从 `0.13~0.28` 强压至 `0.035~0.045`（全集均値 `0.0176`）后：
   - 同机制迁移题**并未继续上涨**（仍为 **`3 / 12`**，`WT03, WT05, WT06` 通过，`WT11` 未翻转），说明每类仅 2 道错题（共 8 题）不足以稳定教会静态权重泛化出 `WT11`；
   - 异机制保留题改动面从 `6 / 12` 扩大到 `10 / 12`，保留得分从 `4 / 12` 回落至 **`3 / 12`**（虽仍优于无约束 96 步 `lora_conv` 的 `2 / 12`，但重新损失了 1 分，总分回到 `6 / 24`）。
3. **跨全谱系的清晰单调规律（克制度 → 保留集得分）**：在相同 96/64 步训练区间内，训练期 KL 约束强度与异机制保留能力呈现严格单调正相关：
   - `lambda_kl = 0.0`（96 步无约束）：保留集改动 `12/12` → 保留得分 **`2 / 12`**（净退化 `-2`）；
   - `lambda_kl = 1.0`（96 步中约束）：保留集改动 `10/12` → 保留得分 **`3 / 12`**（净退化 `-1`）；
   - `lambda_kl = 2.0`（64 步强约束）：保留集改动 `6/12` → 保留得分 **`4 / 12`（净退化 `0`，100% 零遗忘！）**。

## 3. 核心科学洞察：下一步真正值得攻克的是什么？

通过这轮完整闭环实验，原本混在一起的两个问题已经被彻底剥离开并解决了一半：
1. **已解决的问题（“训深伤异类能力”）**：用 **无关普通题全词表 KL 散度自蒸馏锚定（`lambda_kl=2.0` + 适度步数止盈 `loss ≈ 0.09`）** 即可在不改任何推理代码的情况下把异类保留退化压回 **`0`**（`99.15%` 未见异类 token 一致率，`4/12` 保留分完好无损）。
2. **真正卡住最后 1 分的本质瓶颈（8 样本数据稀疏性，每类仅 2 题）**：哪怕把 `V06/V07/V08` 训到 `loss = 0.035`（Gate G7-R2），静态低秩矩阵从 **每类仅 2 道错题** 中提炼出的泛化规律也稳定停在 `3 / 12`——若想在不伤保留的前提下让外挂 LoRA 的迁移能力从 `3/12` 进一步超越长提示词 `4/12`，关键不再是继续压低这 8 道题的训练 loss，而是**扩充目标领域的合成/历史错题样本量（例如每类从 2 题扩到 10–20 题，同时保留 `KL=2.0` 背景锚定）**——因为外挂 LoRA 最大的系统绝活正是**“不管吃下 8 道题还是 800 道题，外挂体积永远锁死 `14.62 MiB`、推理永远快 `9 倍`”**（而长提示词根本塞不下 80 道题！）。
