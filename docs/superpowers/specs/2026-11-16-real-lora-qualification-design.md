# 真实 LoRA 训练链路验收

承接用户在远端环境检查完成后对“真实模型加载、固定 16 步更新、保存重载及
冻结推理”的继续指令。沿用已经批准的 pilot 和 adapter 设计，不改研究问题。
本阶段只验收工程链路，不执行模型生成的代码，不打开迁移/保留评分答案。

## 选择

采用“既有核心 + 单次私有远端启动脚本”。相比新增通用训练 CLI 或接入 PEFT，
这一方案不新增依赖、不改变训练算法，也不把实验侵入主推理引擎。
本地真实预训练执行不在范围内；Mac 只运行小张量合成测试。

## 固定接口

新增 `training_roundtrip.run_roundtrip(model, dataset, artifact_path, *, emit=None)`：

- 调用方传入单设备 BF16、eval、冻结底座和已经验证的八行训练输入。
- 拒绝已有输出文件，再调用现有训练核心；不得调节配置、重试或挑 checkpoint。
- 使用第一条监督题的完整 prompt（不含答案）做五次确定性 forward：
  训练前底座、训练后初始适配器、最终适配器、重载最终适配器、最终卸载底座。
  `use_cache=False`、`return_dict=True`，无 autocast、无 sampling。
- 保存用于比较的末位置 logits 到 CPU 内存，不写明文答案或 logits 到公开输出。
  要求初始适配器与底座完全一致、重载前后完全一致、卸载后底座完全一致，
  且 logits 有限。其余完整性检查沿用 `train_adapter`/`mounted_adapter`。
- 保存/加载使用既有安全 API；保存失败或任何检查失败直接抛错，保留文件。
- 返回 JSON-native 核心 receipt、artifact 摘要/字节数、往返检查、分阶段
  墙钟（非重复加总）、本封装墙钟和 CUDA peak allocated/reserved。
  CPU peak 写 null，不伪装 GPU 成本；完整业务成本依然未测量。
- 可选 `emit` 仅报告阶段名称与不含监督内容的统计，供远端进度观察。

## 远端顺序

1. 将逐文件哈希绑定的代码和仅八条监督数据放入新建 0700 私有目录，
   文件 0600；不传完整题库或评分材料。保持已验证的严格 SSH 别名路线。
2. 固定既有解释器/完整安装版本表、模型配置/tokenizer 五个已冻结摘要和
   本次观察的全部权重分片摘要。隔离启动 `-I -S -B`，显式 package 路径，
   禁下载、遥测、安装、其他后端和动态 remote code。
3. 先在远端 CPU 上用极小随机 Qwen3 及合成八行输入验收同一新封装。
   这是兼容性诊断，不是额外真实模型训练或候选搜索。
4. 兼容性通过及独立代码审查接受后，重新核实既定 GPU UUID 的空闲显存、
   计算进程与设备映射；一张卡、一个新 run 目录、一轮真实训练。
   无可用设备则停止，不终止别人的进程，不自动切卡。
5. 加载既有 safetensors 为 BF16，使用 eager attention，冻结底座、
   禁 KV cache；从固定监督 bytes 经 `prepare_training` 构造数据。
   完成固定的 rank8/alpha16/q-v/seed42/AdamW5e-5/16steps，保存初始与最终状态。
6. 真实训练连接含检查、加载及往返上限 3600 秒，不自动重试/增卡/续时。
   独立父进程等待本次模型子进程最多 3500 秒，超时只终止该子进程组，
   两次终止等待各最多 3 秒；若仍无法确认退出，保留未知状态而不是报通过。
   兼容性是另一个合成诊断，父进程等待上限 240 秒。它不是断连清理服务。
   自动断连清理和聚合
   内存/磁盘配额已被用户取消；不重建它们。物理资源失败仍如实记失败。
   连接中断则状态未知，先人工式查询本次 run，不重新启动训练。
7. stdout 只传 JSON 阶段消息与最终 receipt，不传答案/token IDs。
   启动、训练及收集的任何异常保留原日志；无完成标记或 exit 非零不报通过。

## 验证与边界

新增测试不在 discovery 时导入 torch，保持原有冷启动测试。
真实小张量验证五次 forward 的输入/缓存/状态、16 次训练调用、错误传播、
已有 artifact 拒绝、有限值与保存重载一致性。独立审查后才启动真实加载。

本轮不生成/执行候选，不建立 LoRA 对 text 的收益，不证明 RSI。
全部 scientific/admission flags 仍为 false。已有封存文件和失败记录不修改，
不重跑 1416 项验证、不提交/推送本轮文件、不更新记忆。
