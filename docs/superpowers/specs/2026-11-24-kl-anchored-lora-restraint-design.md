## 1. 路线 A（Gate G6-A）实测早停结论与几何病根诊断

在完全不接触 `WT01..WR12` 测试集的前提下，单次只读探路实验 **Gate G6-A**（`run_id=0a5cbbc5291c83a102d977844562cdee`，40 道题裸底座中后层 `18..30` 隐状态提取耗时仅 `4.62s`）已完成并触发预设早停止损线：

1. **留一法校准表现**：在 `V01..V08`（8 道 `v2` 监督题）与 `R01..R16`（16 道 `v1` 背景题）上留一法平衡准确率为 `1.0`（正样本分 `0.6266..0.8268`，背景最高分 `0.4567`，自动最大间隔阈值 $\tau = 0.5416$），且未见异类探针 `D01..D04` 误开率为 `0 / 4`（`-0.0593..0.3066`）。
2. **未见同机制探针召回未达标（触发早停）**：在独立开发集 `C01..C12`（12 道未见同机制题）上，尽管 **11 / 12 道题的最近邻锚点准确命中同机制伙伴** 且分数（`0.3732..0.7156`）整体高于 `D01..D04`，但在自动阈值 $\tau = 0.5416$ 下仅打开 **`4 / 12`（33.3% < 预设门禁 `9 / 12`）**。
3. **几何根因（为何外置余弦硬开关走不通）**：对 `V01..V08` 去底噪原型的 $8\times 8$ 内积矩阵分析显示，**不同机制之间**的平均余弦相似度高达 **`0.5814`**（最高 `0.7789`），而**同机制内部**平均余弦为 `0.7007`（真实机制净增量仅 `+0.119`）。原因在于整题平均隐状态中混入了大量“多约束长函数题型风格分量”：若维持高阈值会漏关同机制题，若强行下调阈值则同属多约束风格的异机制保留题 `WR01..WR12` 也会因共享 `+0.58` 风格分量而被误开。

因此严格执行 `2026-11-23-gated-lora-on-demand-switch-design.md` 第 5.1 节早停规则：**终止路线 A，不跑 Gate G6-B，直接切入用户预定的路线 B（训练期克制约束）**。

## 2. 路线 B 核心思想：把“按需软开关”直接训进标准 LoRA 的零空间

路线 A 失败的本质是“用人工池化的单向量余弦去一刀切整题风格与局部算法机制”；而路线 B 直接利用 36 层端到端梯度，在保持 **推理期 100% 纯标准 `rank-8` `(A, B)` 静态权重（`14.62 MiB`、零外置路由器、零额外耗时）** 的前提下，修改训练目标：

$$\mathcal{L}_{\text{RouteB}}(\theta_{\text{LoRA}}) = \mathcal{L}_{\text{CE}}\big(p_{\theta}(y_{\text{ref}} \mid x_p)\big) + \lambda_{\text{KL}} \cdot \frac{1}{2}\sum_{m=1}^{2} D_{\text{KL}}\Big(p_{\text{base}}\big(\cdot \mid x_{b_m}, \hat{y}^{\text{base}}_{<t}\big) \;\Big\|\; p_{\theta}\big(\cdot \mid x_{b_m}, \hat{y}^{\text{base}}_{<t}\big)\Big)$$

其几何机制直接对应“无开销软门控”：
1. **对异类/通用 Python 方向形成 Fisher/KL 零空间投影**：在 16 道无关普通代码题 $B = \{\text{R01}\dots\text{R16}\}$ 上，锚定冻结底座自身贪婪输出轨迹 $\hat{y}^{\text{base}}$ 的**全词表条件分布**。一旦某层 LoRA 下投影矩阵 $A$ 试图响应通用 Python 循环、边界判断或返回语法特征 $h_{\text{generic}}$，就会扰动 $R01\dots R16$ 的词表分布并受到二次型 Fisher 惩罚 $\lambda_{\text{KL}} D_{\text{KL}}$，迫使优化器将 $A$ 的行空间自动正交化到通用特征的**零空间**（$A h_{\text{generic}} \approx 0$）。
2. **避免末期逐字死记硬背**：Gate G5 实测显示第 8 轮平均监督 loss 已达 `0.0461`（已充分掌握修复规律），而第 9–12 轮继续压至 `0.0130` 纯属记忆局部临时变量名。路线 B 采用 **`8` epochs = `64` 步** + `AdamW(lr=2e-4 -> 2e-5, weight_decay=0.01)` + `lambda_kl = 2.0`（每步 1 条目标监督题 + 2 条无关背景锚定题，每轮完整覆盖 `8` 道正样本与全部 `16` 道背景锚点）。

## 3. 严格数据隔离与训练/评测流程（Gate G7）

1. **零泄漏数据分工（沿用已钉死 SHA256）**：
   - 正样本监督集 $P$：`confirmatory_v2_r1/supervision.json`（`V01..V08`，8 题）——提供监督参考解 $y_{\text{ref}}$；
   - 无关背景锚定集 $B$：`data/prompts_v1.json` 中 `R01..R16`（16 题，去编号脱敏提示词）——**不使用任何人工标签或参考解**，仅在训练前用原装裸底座贪婪生成最多 `128` token（遇 EOS 即停）自蒸馏轨迹并缓存底座 BF16 精确目标位置 logits；
   - 独立未见异类漂移审计集 $D_{\text{neg}}$：`data/prompts_v1.json` 中 `D01..D04`（4 种完全未见机制，不参与训练）——训练完成后立即实测未见异类题上的全词表平均 $D_{\text{KL}}(p_{\text{base}} \| p_{\text{LoRA\_kl}})$ 与 Top-1 贪婪 token 一致率；
   - 端到端评估集 $E$：`confirmatory_v2_r1/prompts.json` + `oracles.json`（`WT01..WT12` 迁移 + `WR01..WR12` 保留，共 24 题 + `WT01/WR01` 双 `base_canary`）。
2. **推理期零改动**：
   - 训练产出的 `kl_anchored_adapter.pt` 与 Gate G4-B / Gate G5 的适配器张量结构 **100% 逐维相同**（72 个 FP32 张量，共 `15,335,424` bytes = `14.62 MiB`），直接通过 `mounted_converged_adapter` 一次性挂载完成全部 24 道评估题双轮贪婪生成，随后由 Phase 2 远端 CPU `bwrap`+`seccomp` 沙箱完成全量 8 用例评分。

1. 新增独立模块 `experiments/lora_necessity/kl_anchored_lora_ablation.py` 与 `experiments/lora_necessity/test_kl_anchored_lora_ablation.py`（零 `#` 注释、零单字母 AST 标识符、不改动任何已有文件）。
2. 本地 PyTorch 微型 Qwen3 真梯度单测必须证明：相比无约束训练（`lambda_kl=0`），开启 `lambda_kl=2.0` 在同样使监督集 CE loss 显著收敛的同时，将背景锚定集上的全词表 KL 散度压低至少 **`5×`**。
3. 端到端评估对比维度（`lora_kl` vs `base` / `lora_conv` / `text`）：
   - 检验 `WR01..WR12` 保留集通过数能否从 `lora_conv` 的 `2 / 12` 回升（修复 `WR03`、`WR11` 误伤），同时观察 `WT01..WT12` 同机制迁移集能否维持收敛增益，以及 24 题总通过数、首轮输出相对 `base` 的改动比例（克制度）与 `~9×` 系统推理提速。
