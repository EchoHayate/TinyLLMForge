# Light Doc Cache 项目资料

本目录由任务清单整理生成，包含：

- `light_doc_cache_task_plan.md`：适合导入飞书文档或直接阅读的 Markdown 版本。
- `tasks.csv`：22 个任务的项目管理明细表，可导入飞书多维表格、Excel、Notion、Jira 等工具。
- `phase_summary.csv`：6 个阶段的工作量汇总表。

整理说明：

- 保留原始 6 阶段、实际列出的 23 个任务、约 86 PD 的规划结构。
- 原文标题和总览写作 22 个任务，但明细任务 ID 合计为 23 个，阶段任务数相加也为 23 个，因此落盘版本按明细修正为 23 个。
- 补齐了原文中因换行截断的少数字段，如“消融结果”“优化后的推理代码”“大纲文档”。
- 将两个 go/no-go 风险关口标注到任务备注中：T1.3 和 T4.3。
